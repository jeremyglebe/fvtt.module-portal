Installation

  1. Sign in. For a public module, copy its public manifest URL.
  2. For a private module, request access first. Once approved, generate a link; it expires after 30 minutes.
  3. In Foundry, open Add-on Modules → Install Module for modules, or Game Systems → Install System for systems, and paste the link into Manifest URL.
Updating an installed module

Public modules update through their original manifest URL. For private and secret modules, generate a link for the new version and use Install Module (or Install System) again. The matching package ID replaces the existing installation. Back up any edits to module files or compendiums first. Private modules can expose version notices, but automatic downloads are unavailable. Secret modules have no public version notices; check this site for their updates.

Download limits and replacements

Private and secret releases include one download. A link is used when the ZIP transfer starts, even if it fails. To try again or get another copy, select Request replacement and explain why. An administrator must approve it. Do not share installation links.
