What about Foundry’s automatic updater?

Your installed module checks a permanent public manifest for new versions. Automatic installation is intentionally unavailable and may show an update error. Return here to claim the new release, then use Install Module again. Back up changes made directly to module files or compendiums first.

What if a download fails, or I need another copy?

A link is consumed when a ZIP download starts, even if the transfer fails. It cannot resume or retry. Use “Request replacement” on the release and explain what happened. An administrator can approve another link. An unused link can be passed to someone else, so treat it like a password; this is access control, not copy protection.
