Account policies

Installation

  1. Sign in and request access to a module.
  2. Once approved, generate an installation link. It expires after 30 minutes.
  3. In Foundry, open Install Module and paste the link into Manifest URL.
Updating an installed module

Generate a link for the new version and use Install Module again. The matching module ID replaces the existing installation. Back up any edits to module files or compendiums first. Foundry can detect new versions, but automatic updates are unavailable and may report an error.

Download limits and replacements

Each release includes one download. A link is used when the ZIP transfer starts, even if it fails. To try again or get another copy, select Request replacement and explain why. An administrator must approve it. Do not share installation links.
